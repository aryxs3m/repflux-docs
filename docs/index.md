## Demo site

Try before you install: [demo.repflux.app](https://demo.repflux.app)

## Cloud version

If you don't want to host Repflux yourself, you can use the free cloud version at [cloud.repflux.app](https://cloud.repflux.app).

There is no limitations, the instance is hosted in the EU and is GDPR compliant. You can download your data at any time
and delete your account if you want to.
